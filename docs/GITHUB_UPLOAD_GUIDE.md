# How to Upload This Project to GitHub (No Terminal Needed)

## Step 1: Create a GitHub account
1. Go to https://github.com and click **Sign up**.
2. Enter your email, a password and a username. Verify your email.

## Step 2: Extract the ZIP file
1. Find `Introduction-to-Artificial-Intelligence-Practicals.zip` on your computer.
2. Right-click it and choose **Extract All** (Windows) or double-click it (Mac).
3. Open the extracted folder. You should see: `practicals`, `outputs`, `docs`, `README.md`, `requirements.txt`, `.gitignore`.

## Step 3: Create a new repository
1. On GitHub, click the **+** (top right) and choose **New repository**.
2. **Repository name:** `Introduction-to-Artificial-Intelligence-Practicals`
3. **Description (optional):** Python practicals for Introduction to Artificial Intelligence.
4. Choose **Public** or **Private**.
5. Do **NOT** tick "Add a README file" (you already have one).
6. Click **Create repository**.

## Step 4: Upload the files
1. On the new empty repository page, click the link **uploading an existing file**.
2. Open the extracted folder on your computer, select **everything inside it** (`practicals`, `outputs`, `docs`, `README.md`, `requirements.txt`, `.gitignore`).
3. Drag and drop them into the GitHub page. Folders keep their structure.
4. Wait until all files show as uploaded.
5. Scroll down to **Commit changes**, type a message such as `Add AI practicals`, and click **Commit changes**.

## Step 5: Check the result
- The README appears automatically on the main page.
- Click `practicals` to see all 10 files.

## Troubleshooting
- **`.gitignore` is missing after upload:** hidden files may not be selected. Click **Add file → Create new file**, name it `.gitignore`, paste the contents from the ZIP, and commit. It is optional.
- **Folders do not upload when dragged:** use Chrome or Edge, or upload each folder's files one folder at a time (**Add file → Upload files**).
- **Upload the folder contents, not the ZIP itself.**
